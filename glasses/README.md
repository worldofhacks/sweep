# glasses

Capability areas: Interaction and Platform. Milestone: Future, after M4 and the source-access gate in PRD section 5.9.

Any engineer may claim a ready task and owns it through review, integration, and evidence. Changes to the intent contract, source registry, or safety-critical paths name one change owner and require cross-review.

A future Meta Ray-Ban Display web app (Meta Web Apps SDK) may render one video feed, a minimap, and the alert line. It emits the same intents as the webcam console from pinch (select, confirm), D-pad (cycle drones, step formation), drag (altitude), head direction (translate direction, sweep box), middle pinch (cancel; held, e-stop), and Neural Handwriting (language). It needs HTTPS for the app and a `wss://` path to the relay on the same network (a page served over HTTPS cannot open a plain `ws://` connection); the shared token lives in the config page, not the URL.

Registration gate: real glasses events pass the same intent tests as the webcam console before the source joins the production relay (PRD sections 5.1 and 5.9).

PRD: sections 5.9, 7.2.
