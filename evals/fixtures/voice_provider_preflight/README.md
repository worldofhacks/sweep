# Provider transport preflight recording

`en-us-stop.ogg` is a 0.894-second US-English pronunciation of “stop.” Dvortygirl recorded it on 18 March 2006 and published it on Wikimedia Commons under CC BY-SA 3.0. `source.json` records the source page, license, and SHA-256 for the committed bytes.

The Deepgram and Whisper cassettes were captured from one live request per provider using this file. They establish that each configured transport can submit real audio and replay its captured response. The 20-recording smoke set remains pending, including its accuracy and latency results.
