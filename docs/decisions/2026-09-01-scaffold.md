# Scaffold decisions

Decision record from the 2026-09-01 scaffold session. The step-by-step plan that built the
repository has been removed; everything it produced is in the tree, and these are the choices
that are not obvious from reading it. Product source of truth: `docs/prd.md`.

| Decision | Choice | Why |
|---|---|---|
| Scaffold depth | bare skeleton: layout, READMEs, toolchains, one layout test, CI, compose; no contracts as code | the team freezes the contracts itself; pre-built models would pre-empt that |
| Python | uv, Python 3.12 only (`>=3.12,<3.13`), pytest, ruff | ROS 2 Jazzy targets 3.12 |
| Packaging | flat top-level packages per PRD Appendix D; project not installed (`tool.uv.package = false`); run modules as `uv run python -m pkg.module` from the repo root | keeps the frozen layout literal and keeps generic names such as `evals` out of site-packages |
| Layout guard | `tests/test_layout.py` imports every declared package, checks its file lives in this repo, and rejects undeclared top-level packages | catches `.venv` impostors and layout drift; the one contract a test can enforce today |
| ruff | E, F, I, B, UP; excludes `console/`, `datasets/`, and `*.md` | ruff 0.16 rewrites Python fences inside Markdown |
| Console | Vite + React + TypeScript with pnpm, static output | panels re-render from relay state; the build is still plain files to serve |
| CI | GitHub Actions `python` and `console` jobs, mirrored in `.gitlab-ci.yml`; `just ci` runs the same commands | one definition of green on both remotes and locally |
| setup-uv pin | exact release `v10.0.1` | astral-sh/setup-uv publishes no floating `v10` tag |
| Media | MediaMTX 1.20.1 via compose, no restart policy | a bad config fails fast instead of looping; MediaMTX does not serve MJPEG |
| Branch protection | pull request, one approval, `python` and `console` checks, strict up-to-date, squash merges; admin bypass exists and is not used | PRD section 8.2 |
| GitLab mirror | `labs.gauntletai.com`, remote `gitlab`, created by `just gitlab-remote` after `glab auth login` | course mirror; still pending at time of writing |
